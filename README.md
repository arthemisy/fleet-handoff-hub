# Fleet Handoff Hub

vamos criar um aplicativo para celular para ser usada em equipe, que todos os dados atualizados aqui pelo projeto sejam enviados automaticos para cada celular usando o programa, o programa deve poder ser instalado em cada celular, iphone ou android.

O nome do programa será: " Controle de Frota"
a interface terá o tema da empresa, segue logomarca em anexo.

O aplicativo tem como base controlar uma frota de carros e seus gastos.
Esses carros estão sob controle da empresa EletroMW e a empresa disponibiliza para alguns gestores tais carros, para serem usadas em cada obra de construção em que eles trabalham coms eus funcionários, essas obras são chamadas projetos, pelo tempo que cada gestor esta com os carros (que por sua vez são identificados pelas placas) então cada gasto desses carros é de responsabilidade de cada gestor.

Os gastos são arquivados e todos os dados em uma pasta com nome de cada gestor: 
Maicon Dias, Rafael Pupulim, Cleiton Dias, Orlando Tambani, William Muniz., com opção de criar novas pastas e incluir novos gestores.
Os dados dos gastos dos carros estão na panilha que vou anexar agora:
Como base, para criar a pasta de cada gestor, vou anexar planilhas com cada gestor, cada carro (por placa e modelo) que estão com eles.

Cada vez que um novo carro vai para uma obra nova ou para um novo gestor, ou ate mesmo volta, nós fazemos uma conferencia, e essa conferencia tem um checklist com placa do carro e todos os requisitos que checamos, vou enviar uma print do que conferimos, quero que crie um campo para esse checklist e que seja possivel eu copiar enviar as fotos ou dados da mensagens desse chekclist ate mesmo em formato de print e que não só seja convertido para alimentar os dados da tabela de veiculos, como também haja um campo em que eu possa anexar e salvar, deixar salvo estes dados para conferencias futuras, vou enviar um modelo da mensagem desse checklist feito:
